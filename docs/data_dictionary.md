# Data Dictionary

> ALL DATA IS SYNTHETIC. IDs only, no names. Generated by src/generate_data.py (seed 42).

## Raw tables (data/raw/*.csv, loaded as text into DuckDB schema `raw`)
| Table | Grain | Key columns |
|---|---|---|
| clinics | one row per clinic (12) | clinic_id, city, state, timezone |
| providers | one row per provider (60) | provider_id, clinic_id, provider_type (psychiatrist/NP/therapist), weekly_slot_capacity |
| patients | one row per patient (plus injected duplicates) | patient_id, clinic_id, created_date, age_band, payer_type (dirty), language, prior_no_show_count |
| intake | one row per patient | intake_id, intake_ts, phq9_total, gad7_total, acuity, sdoh_* flags |
| eligibility_checks | one row per check | eligibility_id, patient_id, checked_ts, eligibility_status |
| prior_authorizations | one row per request | pa_id, patient_id, submitted_ts, decided_ts, urgency, status, denial_reason |
| appointments | one row per appointment (plus duplicates) | appointment_id, patient_id, provider_id, scheduled_ts, appt_ts (two timestamp formats), lead_days, modality, status, reminder_arm |
| claims | one row per claim (plus duplicates) | claim_id, appointment_id, billed/allowed/paid_amount, claim_status, denial_code, submit_date, paid_date |
| experiment_assignments | one row per enrolled patient | patient_id, arm, assigned_date |

## Staging (schema `staging`, dbt tables): typed, deduplicated, payer standardized, timestamps normalized to clinic-local time.

## Marts (schema `marts`)
| Model | Grain | Notes |
|---|---|---|
| dim_date, dim_clinic, dim_provider | day / clinic / provider | |
| dim_patient | patient | intake scores, SDOH flags, experiment_arm; payer 'Unknown' = missing in source |
| fact_appointment | valid appointment | flags is_no_show, is_late_cancel, is_cancelled, is_completed, is_resolved; lead_bucket |
| fact_prior_auth | request with a known patient | turnaround_hours, is_sla_breach (NULL if pending) |
| fact_claim | claim with a valid appointment and amounts | days_in_ar, is_first_pass_denied |
| kpi_* (views) | see docs/kpi_definitions.md | |

## Quarantined rows (excluded from marts, counted in reports/dq_report.md)
Orphan keys, appointments before the patient existed, and claims violating paid <= allowed <= billed.
